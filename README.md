# ❤️ Sentiment Analysis using Python

## 📌 About the Project

This project analyzes a given sentence and identifies its sentiment as Positive, Negative, or Neutral.

## 🎯 Objective

The main objective is to understand basic Natural Language Processing concepts using Python.

## 🛠️ Technologies Used

- Python
- Natural Language Processing
- String Processing

## ⚙️ How It Works

1. The user enters a sentence.
2. The sentence is divided into words.
3. Positive and negative words are identified.
4. The words are counted.
5. The final sentiment is displayed.

## 💻 Example

Input:

I love this product

Output:

Positive 😊
